# Parvez SRE Lab

This repository contains a hands-on SRE lab built on AWS using Kubernetes (k3s).

## Goals
- Build and operate a production-like Kubernetes system
- Implement observability (metrics, logs, alerts)
- Define SLIs/SLOs and error budgets
- Run failure drills (GameDays)
- Add AI/LLM-based incident assistance

## Stack
- AWS EC2 (Ubuntu 22.04)
- k3s Kubernetes
- ingress-nginx + AWS ELB
- cert-manager + Let’s Encrypt
- Prometheus, Grafana, Alertmanager
- Loki + Promtail
